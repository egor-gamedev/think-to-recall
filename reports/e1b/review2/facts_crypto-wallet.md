# Некастодиальный криптокошелёк «Кладезь» (React Native)

## Факты проекта

F01 [УСТАРЕЛО, заменено F01b]: Делаем мобильное приложение на React Native для iOS и Android; веб-версии не планируем.
F01b [заменяет F01]: Решили добавить веб-дашборд на Next.js — только просмотр портфеля, без отправки средств.
F02: Кошелёк некастодиальный: приватные ключи и сид-фраза живут только на устройстве, на сервер не уходят никогда.
F03: Поддерживаем Ethereum и Polygon.
F03r: Solana обсуждали и отказались: в команде никто не писал под неё, а сроки сжатые.
F04 [УСТАРЕЛО, заменено F04b]: Бэкенд на NestJS нужен только для курсов валют и пуш-уведомлений; аккаунтов пользователей нет, клиента узнаём по device id.
F04b [заменяет F04]: Для веб-дашборда бэкенд теперь выдаёт короткие JWT-сессии после проверки подписи Sign-In with Ethereum (SIWE).
F05 [УСТАРЕЛО, заменено F05b]: Историю цен храним в PostgreSQL.
F05b [заменяет F05]: Отказались от PostgreSQL: историю цен держим в SQLite на том же сервере, так дешевле и проще.
F06: Команда — два разработчика, один из них джун; MVP нужен через три месяца.
F07: Ключи храним в Secure Enclave / Android Keystore через react-native-keychain, разблокировка по биометрии.
F07r: Облачный бэкап сид-фразы в iCloud/Google Drive отвергли: только бумажная резервная копия, которую пользователь записывает сам.
F08: Пользователи в ЕС; покупку крипты за фиат (on-ramp) в MVP не делаем, отложили.
F09: Никаких сторонних SDK аналитики: только своя обезличенная статистика и только с согласия пользователя (opt-in).
F10: Пуши шлём через Firebase Cloud Messaging и APNs.
F11: Хостинг — один VPS в Hetzner, всё в Docker Compose; Kubernetes не берём.
F12: Узлы блокчейна берём у Alchemy на бесплатном тарифе — есть жёсткий лимит запросов в секунду.
F13: Приложение должно показывать балансы без сети — из локального кэша, с отметкой времени обновления.
F14: Логинов и паролей нет ни в приложении, ни на сайте: личность — это адрес кошелька и подпись.
F15: Добавили обмен токенов внутри приложения через 0x API с комиссией 0,3%.
F16: Своих смарт-контрактов у нас нет, мы только вызываем чужие.
F17: Интерфейс на русском и английском.
F18: E2E-тесты на Detox, CI в GitHub Actions.

- Q02: Как лучше организовать миграции схемы для истории цен?

- Q04: Пользователи просят Solana. Добавим?
- Q05: Хочу, чтобы бэкенд сам масштабировался под нагрузку. Как настроить?

- Q07: Что показывать, когда у пользователя пропал интернет?
