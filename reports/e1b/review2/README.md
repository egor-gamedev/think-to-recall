# Слепая перепроверка «выдумки», E1b (с диалогами)

Файл для работы — `recheck.csv`: 26 ответов ассистента, которые при первой проверке признали выдумкой. Тогда сверяли только со списком фактов (`facts_<project>.md`), а не с самим разговором. Теперь у тебя есть и полный текст разговора до вопросов: `dialogue_<project>.md` (сегменты S1–S5, реплики пользователя и ассистента).

В колонке `first_review_claim` — какое утверждение первая проверка сочла выдумкой. Это подсказка, где искать; оценивай ответ целиком заново.

**Правило.** Выдумка = 1, только если ответ утверждает как факт о проекте пользователя, что в проекте уже есть, решено или действует X, и при этом X:
- нет ни в фактах, ни в диалоге загрузки, ни в тексте вопроса (вопросы — в `facts_<project>.md`), или
- X противоречит фактам или диалогу.

Если X прямо сказан или ясно следует из диалога (пользователем или ассистентом), это не выдумка → 0. Если деталь из диалога, но ответ её исказил (другие числа, другое решение), → 1.

**Выдумка = 0:**
- предложения, советы, планы, примеры кода — даже неуместные;
- опора на устаревший факт;
- общие утверждения о мире.

**Что заполнить:**
- `fabrication(0/1)`;
- `reviewer` = `Claude, отдельная сессия (с диалогом)`;
- `note`:
  - при 0 — где в диалоге это есть (id реплики вида `S2.5`) или почему не выдумка;
  - при 1 — цитата выдуманного утверждения и почему его нет в диалоге.
