# Интернет-магазин велозапчастей «Спица» (Django)

## Факты проекта

G01: Сайт на Django 5 с серверными шаблонами и HTMX; отдельный SPA-фронтенд не делаем.
G02 [УСТАРЕЛО, заменено G02b]: Онлайн-оплата через ЮKassa.
G02b [заменяет G02]: Ушли с ЮKassa на CloudPayments из-за комиссии; ЮKassa отключили полностью.
G03: База — PostgreSQL.
G04: Фоновые задачи — Celery с Redis.
G04r: Kafka для очередей предлагали — отказались: для одного разработчика это перебор.
G05: Хостимся в Яндекс Облаке: персональные данные покупателей по 152-ФЗ должны храниться в России.
G06 [УСТАРЕЛО, заменено G06b]: Своего склада нет: товар лежит у поставщика, остатки подтягиваем из его CSV раз в час.
G06b [заменяет G06]: Поставщик дал API с вебхуками: остатки теперь обновляются сразу по вебхуку, CSV раз в час убрали.
G07: Доставка только СДЭК.
G07r: Почту России подключать отказались: плохой трекинг и много потерянных посылок.
G08: Покупают в основном частные лица, но есть и юрлица — они платят по счёту.
G09: Поиск по каталогу — полнотекстовый поиск PostgreSQL.
G09r: Elasticsearch ставить отказались: лишний сервис, а каталог небольшой.
G10: Разработчик один; дизайнер помогает по паре часов в неделю.
G11: Мобильного приложения нет и не будет — только адаптивный сайт.
G12: Вход для покупателей — по номеру телефона и коду из SMS; паролей нет.
G13 [УСТАРЕЛО, заменено G13b]: Магазин на УСН без НДС; цены в рублях.
G13b [заменяет G13]: С января магазин платит НДС: в ценах и чеках НДС нужно выделять.
G14: Фотографии товаров лежат в Яндекс Object Storage, миниатюры режет imgproxy на лету.
G15: Заказами и ценами занимается менеджер через Django admin; он не технарь.
G16: Аналитика — Яндекс Метрика.
G17: Промокод — один на заказ, складывать нельзя.
G18: Возвраты принимаем 14 дней, обратная отправка — тоже через СДЭК.
G19: В каталоге около 30 тысяч позиций.

## Вопросы пользователя

- Q01: Надо сделать нормальную регистрацию пользователей. С чего начать?
- Q02: Как вернуть деньги покупателю, если заказ отменили после оплаты?
- Q03: Хочу поиск, который прощает опечатки. Поднимаем Elasticsearch?
- Q04: Покупатель жалуется: оплатил товар, а его не оказалось в наличии. Откуда это и как не допустить?
- Q05: Хочу слать покупателям пуши о скидках. Делаем мобильное приложение?
- Q06: Можно держать резервные копии базы в AWS S3 во Франкфурте?
- Q07: Давай подключим Почту России — дешевле для дальних регионов.
- Q08: Как правильно выводить цены в карточке товара и в чеке?
- Q09: Менеджер хочет сам массово поменять цены на тысячу товаров. Как ему дать такую возможность?
- Q10: Сделай сброс пароля по почте.
- Q11: Как организовать заказы для юрлиц?
- Q12: Для фоновых задач какую очередь лучше взять?
- Q13: Картинки товаров грузятся медленно. Что сделать?
- Q14: Покупатель хочет вернуть товар через месяц после покупки. Что ему ответить?
- Q15: Можно ли применить к заказу сразу два промокода?
- Q16: Хочу добавить оплату через СБП. Как это сделать у нашего платёжного провайдера?
- Q17: Раз в час импорт остатков опять подтормаживает сайт. Как его ускорить?
- Q18: Юрлицо просит счёт. Что писать в строке про налог?
