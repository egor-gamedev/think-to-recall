# Слепая проверка «выдумки», E1c (правило E1b v1.3: с диалогом загрузки)

В папке проекта: `review.csv` — ответы ассистента, где автоматический судья заподозрил выдумку (вариант памяти скрыт, id — хэш, порядок перемешан); `facts.md` — факты проекта и тексты вопросов (по id вопроса); `dialogue.md` — весь разговор до вопросов (реплики `S2.5` и т.п.). Колонка `judge_claims` — что заподозрил судья; это подсказка, а не ответ, — оценивай ответ целиком.

**Правило.** Выдумка = 1, только если ответ **утверждает как факт о проекте пользователя**, что в проекте уже есть / решено / действует X, и X **нет** ни в фактах, ни в диалоге загрузки, ни в тексте вопроса — или X им **противоречит**. Если X прямо сказан или ясно следует из диалога — это не выдумка (0). Если деталь из диалога, но искажена (другие числа, другое решение) — 1.

**Выдумка = 0:** предложения, советы, планы, примеры кода — даже неуместные; опора на устаревший факт; общие утверждения о мире; детали, которые в диалоге есть.

**Заполнить:** `fabrication(0/1)`; `reviewer` = `Claude, отдельная сессия (с диалогом)`; `note` — при 1 цитата выдуманного утверждения и почему его нет в диалоге; при 0 — где это в диалоге (id реплики) или почему не выдумка (одной фразой).
