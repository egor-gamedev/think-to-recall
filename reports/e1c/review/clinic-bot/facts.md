# Telegram-бот записи в стоматологию «Белая линия» (aiogram 3 + учётная система «СтомаОфис»)

## Факты проекта

C01: Бот на Python и aiogram 3, работает через вебхук на VPS в Selectel (Москва).
C02 [УСТАРЕЛО, заменено C02b]: Расписание читаем и записи создаём напрямую в базе Firebird учётной системы «СтомаОфис» на сервере клиники, через туннель WireGuard.
C02b [УСТАРЕЛО, заменено C02c] [заменяет C02]: Вендор «СтомаОфис» запретил прямую запись в базу под угрозой снять клинику с поддержки; перешли на их облачный API с лимитом 60 запросов в минуту — и чтение, и запись через API.
C02c [заменяет C02b]: Вернулись к чтению расписания напрямую из Firebird — под read-only пользователем, с письменного разрешения вендора; создание и отмена записей — только через API.
C03 [УСТАРЕЛО, заменено C03b]: Напоминание о приёме — одно сообщение в боте за 24 часа до приёма.
C03b [УСТАРЕЛО, заменено C03c] [заменяет C03]: Напоминаний два: за 24 часа и за 2 часа до приёма.
C03c [заменяет C03b]: Напоминание одно — за 48 часов, с кнопкой «Подтверждаю»; кто не подтвердил за сутки до приёма, того бот не отменяет, а передаёт регистратуре на обзвон; напоминание за 2 часа убрали.
C04: У клиники два филиала — Калининград (ул. Горького) и Зеленоградск; часть врачей работает в обоих.
C05: Пациента опознаём по номеру из кнопки «Поделиться контактом» и ищем карту в учётке по телефону.
C06: Телефоны в учётке записаны вразнобой (8…, +7…, с пробелами и скобками); сравниваем по последним 10 цифрам.
C07: На один телефон в учётке бывает несколько карт (члены семьи) — бот спрашивает, кого записать.
C08: Новых пациентов без карты бот записывает только на первичную консультацию 30 минут.
C09 [УСТАРЕЛО, заменено C09b]: Через бота записываются только к терапевтам и гигиенисту; к хирургам и имплантологам — через регистратуру.
C09b [заменяет C09]: К хирургам и имплантологам в боте теперь можно записаться, но только на консультацию, не на операцию.
C10: Договор с фиксированной суммой: сдача 15 декабря, затем 3 месяца гарантийной поддержки.
C11: После гарантии бот сопровождает приходящий айтишник клиники Вадим: знает Windows и 1С, Python — нет.
C12: В логах ФИО и телефоны маскируются — требование юриста клиники.
C13: Отменить запись в боте можно не позже чем за 12 часов до приёма; позже — только звонком в регистратуру.
C14: Уведомления о новых записях и отменах бот шлёт в общий Telegram-чат регистратуры.
C15: Для API есть песочница вендора; копии боевой базы Firebird для тестов нет — главврач не разрешил выносить базу.
C16: Через 3 часа после приёма бот просит оценку от 1 до 5: на 5 даёт ссылку на отзыв в 2ГИС, на 1–4 пересылает отзыв управляющей Ирине.
C17: Детей клиника не принимает — записывать в боте можно только взрослых.
C18: Время приёмов — калининградское, на час меньше московского, а сервер живёт по Москве: время в боте надо переводить.
C19: Уведомления из чата регистратуры читают только в часы работы регистратуры на общем компьютере — ночью и в воскресенье их никто не видит.
C20: Цены в боте не показываются.
C21: Запись в боте возможна максимум на две недели вперёд: дальше сетка врачей ещё не открыта.
C22r: Telegram Mini App для выбора слота отказались делать: после сдачи его некому поддерживать; только inline-кнопки.
C23r: LLM-ассистента для записи свободным текстом отказались делать: главврач боится ошибочных записей.
C24r: Приём фото и рентгеновских снимков через бот отказались делать: медданные в Telegram не гоняем.
