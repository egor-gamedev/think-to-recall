```r
library(dplyr)
library(readxl)
library(purrr)

read_treasury <- function(path) {
  year <- as.integer(sub(".*_(\\d{4})\\.xlsx$", "\\1", path))
  df <- read_excel(path, skip = 5, col_names = FALSE)
  df %>%
    select(region = 1, tax_rev = 4, transfers = 9) %>%   # номера колонок проверьте по файлу
    filter(!is.na(region)) %>%
    mutate(year = year)
}

files <- list.files("data_raw/treasury", pattern = "\\.xlsx$", full.names = TRUE)
treasury <- map_dfr(files, read_treasury)
```

- `eq_grants_pc_l1:high_dep` — *разница* эффекта для группы выше медианы. Если H2 верна — она отрицательна.
- Суммарный эффект для высокодотационных — сумма двух коэффициентов; его ошибку считайте через линейную комбинацию.

**[S6.5] Ассистент:**

Проверка линейной комбинации коэффициентов — через ковариационную матрицу оценок:

```r
b <- coef(m_h2)
V <- vcov(m_h2)
k <- c("eq_grants_pc_l1", "eq_grants_pc_l1:high_dep")
est_sum <- sum(b[k])
se_sum  <- sqrt(sum(V[k, k]))
c(estimate = est_sum, se = se_sum, t = est_sum / se_sum)
```

Или короче через `car::linearHypothesis(m_h2, "eq_grants_pc_l1 + eq_grants_pc_l1:high_dep = 0")`.

Для текста результат удобно перевести в масштаб 1000 рублей на человека: суммарный эффект −0,00059 × 1000 = −0,59 п.п. налоговых усилий для группы выше медианы против −0,21 п.п. для группы ниже. Это понятнее комиссии, чем числа с четырьмя нулями.

Тогда run_all.R — это короткий «дирижёр», который по очереди запускает ваши скрипты в чистом окружении. Код сдаётся приложением, поэтому важно, чтобы с нуля всё воспроизводилось без ручных шагов:

```r
# run_all.R — воспроизводит все результаты с нуля

steps <- c("R/01_load.R", "R/02_merge.R", "R/03_models.R", "R/04_tables.R")
for (s in steps) {
  message("== ", s)
  source(s, local = new.env(), echo = FALSE)
}

writeLines(capture.output(sessionInfo()), "output/sessionInfo.txt")
message("Готово: результаты в output/")
```

Чтобы это работало с нуля, проверьте:
- **Пути только относительные** (от корня проекта). Никаких `setwd("/home/...")` и `C:/Users/...`. Удобно `here::here("data_raw", "file.xlsx")`.
- **Каждый скрипт читает входы с диска** и пишет выходы на диск, а не опирается на объекты в памяти от предыдущего. Тогда `local = new.env()` ничего не сломает.
- **Случайность.** Если где-то бутстрэп — `set.seed()` в начале скрипта.
- **Проверки** `stopifnot` (число наблюдений, число регионов) — уже есть в моделях, это хорошо.

Лучший тест — склонировать проект в новую папку на сервере и запустить `Rscript run_all.R` из терминала, а не из открытой сессии RStudio: так вы поймаете зависимости от вашего окружения.
