# Инди-головоломка «Смотритель» (Godot 4.3, Steam, локализация)

## Факты проекта

I01: Игра «Смотритель» — 2D пиксельная головоломка-адвенчура про смотрителя маяка; движок Godot 4.3, весь код на GDScript, C# не используем.
I02: Код, геймдизайн и тексты делаю один, около 15 часов в неделю после основной работы; арт рисует сестра Вика по выходным, музыку пишет композитор по договору.
I03: Платформы — Windows и нативная Linux-сборка; главная цель — значок Steam Deck Verified, Deck — основное тестовое устройство.
I03r: Порт на Nintendo Switch отвергли: Godot не экспортирует на консоли сам, нужен сторонний портер, а денег на него нет.
I04: Версии под macOS не будет.
I05 [УСТАРЕЛО, заменено I05b]: Локализация: переводы храню в CSV-таблице в репозитории, языки — русский и английский, английский перевожу сам.
I05b [УСТАРЕЛО, заменено I05c] [заменяет I05]: Перешли на gettext .po и Weblate: волонтёры переводят на немецкий, французский, испанский, португальский (бразильский), японский и китайский; языков стало 8.
I05c [заменяет I05b]: Weblate закрыли и вернулись к CSV в репозитории, но с условием: язык попадает в релиз, только если перевод вычитан носителем; на релизе русский, английский и немецкий, японский — если успеет вычитка, иначе патчем.
I06: На мониторах 1920×1080 картинка не займёт весь экран: целочисленный масштаб даёт 1600×1000 с чёрной рамкой по краям.
I07 [УСТАРЕЛО, заменено I07b]: Сохранение — JSON-файл user://save.json, один слот, автосохранение при входе в комнату.
I07b [УСТАРЕЛО, заменено I07c] [заменяет I07]: Сохранения перевёл на Resource: класс SaveGame, ResourceSaver пишет user://slot_N.tres, слотов стало три.
I07c [заменяет I07b]: От .tres отказался: загрузка .tres может выполнить встроенный скрипт, а сейвы игроки пересылают в Discord; теперь бинарный файл через FileAccess.store_var/get_var без объектов, с полем версии, три слота, синхронизация через Steam Cloud.
I08: Композитор Олег по договору: права на музыку остаются у него, у игры неисключительная лицензия; продавать саундтрек отдельно — только с его согласия и с долей 50 % ему.
I08r: Издателя «Пиксель Хаус» отвергли: просили 30 % выручки и права на IP и сиквелы.
I09 [УСТАРЕЛО, заменено I09b]: План: демо на Steam Next Fest в феврале 2027, релиз 1.0 в апреле 2027.
I09b [заменяет I09]: Next Fest перенесён на июнь 2027 — демо не успевает к февралю; релиз 1.0 сдвинут на сентябрь 2027.
I10: Базовая цена в Steam — 12,99 $, региональные цены по рекомендации Steam.
I11: Вишлистов сейчас около 1800; цель до Next Fest — 7000.
I12: Игра линейная, около 5 часов, 4 главы; все уровни и головоломки собраны вручную, процедурной генерации нет.
I13: Платной рекламы не будет: денег на неё нет.
I14: Закрытый плейтест через Steam Playtest, лимит 200 человек.
I14r: Ранний доступ отвергли: игра сюжетная и линейная, недоделанный сюжет в раннем доступе только испортит впечатление.
I15: Собственного шрифта не хватит для японского: нужен отдельный CJK-шрифт.
I16: Управление — геймпад и клавиатура; мышь в игре не используется вообще, курсор скрыт.
I17: Диалоги сделаны в Dialogic 2; строки диалогов выгружаются встроенным экспортом переводов Dialogic в CSV.
I18: Движок заморожен на Godot 4.3 до релиза, на 4.4 и новее не переходим.
I19: Нынешняя сборка без запущенного Steam работать не будет.
I20: Озвучки нет: только текст и «бормотание» — звуки-слоги для каждого персонажа.
I21: Опция отключения вспышек обязательна: свет маяка мигает, а у одного из тестеров фоточувствительная эпилепсия.
I22: Репозиторий на GitHub с Git LFS; CI в GitHub Actions экспортирует сборки и заливает их через steamcmd в ветку beta.
