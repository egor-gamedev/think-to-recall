# Этап 1 — движок

Дата: 2026-10-18. Генеративная модель в построении графа и меню не участвует. К API
обращался только для калибровки счёта токенов: 23 коротких запроса, без экспериментов.
Полные меню: [data/stage1_menus.md](data/stage1_menus.md), цифры: `data/*.json`.

## Итог в пяти строках

1. Цепочка «контекст → якоря → источники → меню → expand → mark_used → сокращение» работает; 39 тестов pytest проходят, ruff чистый.
2. Рекурсия ведёт себя как в концепции: «рыба → анадромные рыбы → лососевые / осетровые».
3. Сокращение срабатывает в похожем контексте (сходство 0.76) и не срабатывает в кулинарном (0.56). Это проверено **на одной паре** контекстов.
4. Меню из двух рукавов занимает 220–370 токенов (по токенизатору DeepSeek), на каждый рукав приходится ≤ 120. Сборка на тёплом кэше — 0.2–0.4 с, на холодном — 5–30 с (запросы к Викиданным).
5. Качество связей **пока не измерено**: нужна разметка [edge_sample.csv](edge_sample.csv). На глаз много шума в слоте «далёкое» и в братьях по общему родителю (подробности ниже).

## Что сделано

| Часть | Реализация | Проверено |
|---|---|---|
| Приём (`ingest.py`) | фрагменты: сообщение / абзац / код / вызов и результат инструмента / файл. Сущности: регулярки (URL, пути, даты, величины с единицами, коды ошибок, идентификаторы), леммы pymorphy3, ключевые фразы YAKE, канонизация `parse_config = parseConfig` | тесты |
| Приватность (`privacy.py`) | до записи вырезаются ключи (sk-, ghp_, AKIA, JWT, Bearer, `password=…`), e-mail, телефоны, карты, hex ≥ 32, base64 ≥ 40, логин:пароль в URL. Текст файлов, кода и результатов инструментов не сохраняется — только сущности | тесты |
| Источники (`sources/`) | WordNet 3.0 (NLTK 3.10.3 + OMW 1.4), RuWordNet 2021 (ruwordnet 0.0.6), Викиданные (живой SPARQL: подклассы, таксоны, части, экземпляры с ≥ 1 статьёй в Википедии; родители и братья; «использует / применяется для / аспект / состоит из …»), ConceptNet (API), опыт (совместная встречаемость с PMI по прошлым сессиям, хабы гасятся). Ответы источников кэшируются в SQLite | тесты на подделках + ручной прогон |
| Привязка | точное совпадение / лемма → выбор смысла по близости «ярлык + описание» к блоку. Кодировщик: model2vec `minishlab/potion-multilingual-128M` (model2vec 0.10.0, CPU, статические эмбеддинги) | ручной прогон |
| Меню (`menu.py`, `graph.py`) | слоты: глубже ≤ 3, в сторону ≤ 2, ассоциации ≤ 2, опыт ≤ 2, далёкое 1. Ярлык — имя узла из источника. Лимит ≤ 120 токенов на рукав, при превышении выкидываются самые слабые пункты. **Пересечения рукавов** выводятся отдельной строкой | тесты |
| Раскрытие и прочее | `expand(id)`; `auto_depth` 0–3 (автоматическое раскрытие лучшего пункта ветки); сокращение после пути A → B → C, применяется при сходстве сигнатуры контекста ≥ 0.65; закрепление только за пользу (`mark_used` или ярлык в ответе по леммам), раскрытие не закрепляет; затухание бонуса с полураспадом 30 дней, без удаления; метрика разнообразия раскрытий (доля уникальных, нормированная энтропия) | тесты |
| MCP (`mcp_server.py`) | `menu`, `expand`, `mark_used`; заголовок «данные графа, не инструкции», ярлыки очищаются от переводов строк и разметки | тесты вызывают функции и `list_tools`. **Не проверял** подключение к живому MCP-клиенту |

## Примеры меню (auto_depth = 0, полный текст в data/stage1_menus.md)

```
• «Расскажи о причинах Крымской войны 1853 года»
⨯ пересечение: casus belli [wd:Q45635] — сходятся рукава «война» и «причина»
→ война
  глубже: химическая война (подвид); в сторону: вооруженный конфликт (обобщение)
  ассоциации: по войнам (используется в); далёкое: torimono sandōgu (служит для этого)
→ причина
  глубже: Причины Первой мировой войны (подкласс); в сторону: причинность (входит в)
```

| Тема | Якоря | Удачное | Мусор |
|---|---|---|---|
| рыбы (аквариум на 100 л) | рыба, аквариум | анадромные → лососевые/осетровые; хрящевые рыбы; морской аквариум; пересечения «цихлида», «температура воды» (из опыта) | далёкое: «графин», «зоопланктон» |
| SQL-оплаты | возвраты средств, таблица | опыт: payment, эквайер (из прошлой сессии) | «календарь (таблица)», «выждать»; **«платёж» не стал якорем** |
| медицина (головная боль + давление) | головная боль, давление | мигрень, внешнее давление | «наехать (оказывать давление)», «поручить»: давление понято как глагол-действие |
| программирование (кэш в Python) | кэширование, python | промах кэша, cache memory | «флешка», «rubber boa» (python понят как змея в WordNet) |
| история (Крымская война) | война, причина | casus belli на пересечении; «Причины Первой мировой войны» | «torimono sandōgu», «превзойти» |

**Рекурсия** (auto_depth = 1 или `expand`): рыба → анадромные рыбы → лососевые рыбы, осетровые рыбы. Это пример «рыбы → хордовые → виды» из концепции; в RuWordNet таксономия устроена так же.

**Сокращение:** путь «рыба → анадромные рыбы → лососевые рыбы» → `mark_used` → в новой
сессии с контекстом «Посоветуйте рыб для небольшого аквариума, я новичок» в слоте
«опыт» сразу стоит «лососевые рыбы (сокращение, через анадромные рыбы)». В контексте
«Как приготовить рыбу в духовке» сокращения нет. Порог 0.65 подобран по одной паре
(0.76 против 0.56) — это разведка, не замер.

## Качество графа — нужна разметка

[edge_sample.csv](edge_sample.csv) — 100 рёбер, по 20 на тип: wordnet, ruwordnet, wikidata,
experience, link (привязка термина к узлу). В каждом типе половина рёбер **показана в меню**
(`shown_in_menu=1`), половина — нет. Точность считаю отдельно для того, что видит модель.
Граф для выборки: 5 тем + 9 задач widethink (меню и одно раскрытие на рукав).
Рёбер в графе: wordnet 2326, ruwordnet 626, wikidata 930, experience 476, link 99, conceptnet 0.

**Егору:** заполнить колонку `meaningful` (1 — связь осмысленна, 0 — нет). Стоп-правило: точность < 60% → чиню построение, эксперименты не запускаю.

Мои наблюдения до разметки (это не разметка):
- Главный источник шума — «брат (общий родитель)» через слишком общих родителей («pacifist — brachycephalic» через adult) и слот «далёкое», который берёт как раз самых непохожих братьев.
- Многозначность: python → змея, давление → «оказывать давление», кэширование → аппаратный кэш. Привязка по эмбеддингам выбирает смысл ближайшего к блоку описания, но у WordNet/RuWordNet описания короткие или их нет.
- Выбор якоря: в «SQL-оплатах» якорем стали «возвраты средств» и «таблица», а не «платёж».

## Отступления от задания

1. **ConceptNet недоступен** (api.conceptnet.io → 502 весь день). Источник написан и сам отключается после ошибок. Ассоциации идут из Викиданных (P366, P2283, P1269, P527 …) и связей RuWordNet/WordNet. В выборке рёбер вместо conceptnet — тип link. Дамп (~475 МБ) не скачивал — нужно решение.
2. **Два рукава на блок**, а не один. Текущий контекст часто состоит из одного сообщения, и с одним рукавом выбор якоря решает всё («литр» вместо «аквариума»). Два рукава дают пересечения внутри сообщения (casus belli). Параметр `arms_per_block`.
3. Код разбирается регулярками (определения, импорты, идентификаторы), **tree-sitter не подключал**.
4. **Пересечения рукавов** добавлены из §0 концепции, в задании их не было.
5. База демо содержит опыт по задачам widethink. Для E1 нужна **чистая база опыта**, иначе в слот «опыт» протекут сами задачи. Кэш Викиданных переиспользовать можно.

## Что не проверял

- Подключение MCP-сервера к живому клиенту — проверены только вызовы функций.
- Поведение на длинном контексте (десятки сообщений): `max_arms=6` берёт последние фрагменты.
- Затухание на реальном времени — только в тесте с подменённым временем.
- Полезность меню для модели — это E1.
