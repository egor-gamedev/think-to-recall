## Что это значит

- **IMLogic — самый точный по смыслу**: ровно формат «похожее недостаточное + далёкое решающее». Но есть два ограничения.
  1. **Лицензия.** Без лицензии в репозитории и при NC-ND у исходного HaluMem использовать IMLogic можно только для некоммерческого исследования. Для README, демо и разговора с инвестором (DECISION_BENCH) это проблема. Нужно письменное разрешение авторов IMLogic или их явная лицензия на данные — предлагаю им написать.
  2. **Опубликованные цифры** (Mem0 38,2 %, EverMemOS 43,5 %, RootMem 55,2 %) — это **точность ответа по 4 вариантам**, а отвечает GPT-5.1. Без вызовов LLM мы можем сравниться только по полноте поиска `memory_l`: у них опубликован Recall@30 для MiniLM, 26,9 %. Точность ответа требует 2 216 вызовов модели. Это не судья, вариант выбирает сама отвечающая модель, но такой прогон всё равно за пределом в 300 вызовов — только после «да».
- **ImplexConv** — лицензия MIT, данные есть, гипотеза «скрытая связь» тоже проверяется полнотой поиска сессий-доказательств. Минусы: набор большой, а метод оценки ответов в карточке не описан.
- **LongMemEval-preference** — маленький (30 вопросов): описательно, не для вывода.
- **Технических проектов нет ни в одном наборе.** Везде бытовые сценарии и персоны: рекомендации, привычки, предпочтения. Значит, по п. 4 твоего дополнения нужны **собственные вопросы в формате IMLogic** на технических проектах. Пример формата: «команда пишет на Next.js → нужен сайт → правильно: сделать на Next.js своей командой».

## Предлагаемый порядок без судьи

1. **MuSiQue / 2Wiki** — идёт сейчас (механика графа, гипотеза «не хуже»).
2. **IMLogic memory-level, Recall@k `memory_l`.** 0 вызовов, ≈ 20–30 мин на Kaggle; сравнение с dense и с MiniLM из статьи. Сначала — вопрос лицензии.
3. **ImplexConv**, подвыборка 200 примеров, Recall@k сессий. 0 вызовов, ≈ 20–40 мин.
4. **LongMemEval-preference**, 30 вопросов, Recall сессии. Описательно.
5. Точность ответа (IMLogic, 2 216 вызовов) и рукава мышления (нужны шаги модели) — отдельные пре-регистрации и твоё «да».
